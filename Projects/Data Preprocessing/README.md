# Data Cleaning & Feature Scaling using Machine Learning

## 📌 Overview

This project demonstrates essential **data preprocessing techniques** used in Machine Learning. It focuses on cleaning customer data and applying feature scaling to make the dataset ready for analysis and ML models.

## 🎯 Objectives

* Clean and preprocess customer data.
* Handle missing and unnecessary data.
* Explore and understand the dataset.
* Apply feature scaling techniques.
* Prepare data for Machine Learning.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

## 📊 Dataset

The project uses a **customer churn dataset** containing customer details and features related to customer retention.

## 🔍 Tasks Performed

### Data Cleaning

* Loaded and explored the dataset.
* Identified and handled missing values.
* Removed unnecessary columns.
* Prepared clean data for further analysis.

### Feature Scaling

* Selected relevant numerical features.
* Applied feature scaling.
* Standardized numerical values for Machine Learning.
